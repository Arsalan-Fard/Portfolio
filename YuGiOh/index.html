2021 · First-year bachelor project

Yu-Gi-Oh

Developing Yu-Gi-Oh (a famous card game) with Java and JavaFX during my first year at Sharif University of Technology. It covers Object Oriented Programming (OOP) and networking concepts for multiplayer gameplay.

Architecture

Project components

01

OOP

Cards, players, decks, boards, phases, and effects are represented as reusable domain classes and enums.

02

MVC-style structure

Models store game state, JavaFX views render each screen, and controllers coordinate rules and menu workflows.

03

JavaFX interface

FXML scenes cover registration, deck building, the card shop, and the turn-based duel board.

04

Client & server

A TCP protocol connects the desktop client to a Java server for accounts and multiplayer state, while AI duels run locally.
